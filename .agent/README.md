## 跑守卫

```bash
python _chk_all.py                      # engine 档（秒级，不需缓存）
python _chk_all.py --data data/x.npz    # 再加 data 档（需一份缓存）
python _chk_all.py --all                # 再加 slow 档（跑战斗/整局）
```

⚠️ **守卫的价值 = 被运行的概率。** 掩码口径错了 4 天没人发现，就是因为当时没有对应守卫、
也没人会挨个去跑那十几个 `_chk_*.py`。改动引擎/布局/动作空间之后**务必跑一遍**。

## 代码注释约定

**工程化注释，不写历史**：只写契约 / 不变量 / 单位 / 用法；短句、命令式。
禁止口语与事故复盘（"实测…""踩过…""曾经…"、日期、"教训"）—— 那类内容进 `notes.md`（逐会话
记录）/ `DIARY.md`（记忆正文），代码里最多留一行指针。能自解释的代码不加注释。
