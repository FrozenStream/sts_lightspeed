# 代码规范化标准（2026-09-24 立 · 全项目适用）

> 目标：**注释简明（用途 / 原理）· 逻辑可读 · 相关功能聚团**。适用根目录 `.py` / `.sh` 与 `realtest/`。
>
> **硬底线（零行为改动）**：不动逻辑、函数签名、指纹字符串（`walk_fp` / `dagger_fp` / `scenario_fp`）、
> RNG 调用顺序、输出格式与命令行接口；⚠️ 关键警告**必须保留**（精炼为一行即可）。
>
> 进度与逐波验证记录 → `.agent/notes.md`。

## 文件头（模块 docstring / 脚本头部注释）

```
一句话定位（是什么线 / 什么工具）
──────────
用途：2~4 行 —— 干什么、为什么存在（动机与结论）。
原理：2~6 行 —— 关键机制、约束、不变量（指纹 / 种子 / 逐位一致 / 引擎路径…）。
用法：
    python xxx.py …        # 常见 2 种以上调用
⚠️ 一行一条：会静默出错 / 会崩 / 会错配数据 的坑（历史复盘去 notes.md，不留在代码里）
```

## 函数与行内注释

- 单行 docstring 说用途；「为什么」不直观时才补 1~3 行 —— 不写"怎么做"的流水账。
- 行内注释只在原理不直观处；日期 / 事件复盘 → `.agent/notes.md`。

## 聚团与可读性

- 文件内顺序：常量 → 基础工具 → 核心机制 → 组装 → 入口；同功能函数相邻。
- 分节横幅沿用 `# ---…--- 名称`（不强制统一长度）。
- 逻辑只做零风险润色（命名、拆表达式）；**控制流不重构**。

## 验证纪律（每波改完必做）

1. `python -m py_compile <改动文件>`；
2. 采集 / 评估线：小样本冒烟与改动前产物**逐位对比**（`np.load` 全键 `array_equal`；
   dagger β=1 对 walk 等价；基线产物放 `data/_norm_tmp/`）；
3. `python _chk_all.py`（engine 档应 12/12 通过）；
4. shell：`bash -n` + 只读子命令冒烟（`usage` / `check`）。

## 开关与权重（2026-09-28 定）

**权重永远存在，开关只决定「要不要用上」。** ⇒

- **不要**为了省几个参数把某层的构造写进 `if <开关>`（权重会随开关存在/消失：旧权重要么加载报错、
  要么形状静默变）。默认写法 = **无条件构造**，`if` 只包住**前向里的使用**。
- 反过来：**开关不能从 `state_dict` 反推** —— 两种取值下键集合与形状完全一样（`strict=True` 拦不住）。
  重建网络必须有配置记录（`train.save_ckpt` 把 `config` 写进**同一个存档文件**，见 `ckpt.py`）；
  没有配置时只能靠**结构性差异**（换模块：`flat` ↔ `factor`）推断，**开关类的必须拒绝**（不猜）。

## 失败与兜底：出错就崩，不做兜底（2026-09-29 定）

**不为「万一」准备降级路径。** 错了就当场崩：抛异常 / `assert` / C++ 直接抛，绝不静默继续。

- **不攒着报**：校验/守卫遇到**第一个**坏值就抛，不要「跑完收集 N 个坏样本再抛」。
- **不做降级开关**：`--allow-unencodable` 这类「容忍坏输入继续跑」的开关一律删 —— 容忍 = 让错值进数据。
- **不用哨兵值表示失败**：`return -1` / `None` / `""` 当「编不出来」用 ⇒ 改成抛。
  ⚠️ `-1` 尤其毒：它在 numpy 里是**合法的末位下标**，会静默写错位置，比崩更坏。
- **不重复校验**：类型转换只在真边界（argv / 读文件 / 外部 JSON）做一次，下游不再查。
- 例外：**哨兵脚本**（`_chk_*.py`）的职责就是统计与报告（扫完全部场景、数出几个坏）⇒ 可以只报不抛；
  运行时路径没有这个待遇。

## 注释时效与数字纪律（2026-09-24 加：药水 43/44 事故复盘）

事故：`potionTypes` 修复后，`runlayout` 的旧注释未同步（仍写"只有 43 列"），又被原样引用进文档 ⇒ 假事实传播。

- **注释只写当前事实**；历史一律显式标注「历史（日期）/已修（日期）」或删除（复盘细节去 notes.md）。
  **改动落地时同波更新受影响注释** —— 谁改行为，谁改注释（改注释不算行为改动）。
- **数字不手抄**：会漂的数字（宽度 / 行数 / 长度）优先写推导来源（表达式、枚举派生）、
  守卫名（`_chk_res` 断言）或运行时查法（`sts.snapshot_layout()`）；确要写就标明"当前值"。
- **引用纪律**：notes / 文档 / 对话引用代码事实前，先用**运行时实测或守卫断言**核对一次；
  注释是线索、不是事实源（本次踩的就是它）。
